# SOWEN V2 Frontend

Frontend Next.js + TypeScript.

## Données

Cette version n'embarque aucun jeu de données statique ou fictif. Les pages compatibles lisent les données du backend NestJS via `NEXT_PUBLIC_API_URL`.

Les modules dont l'API n'est pas encore finalisée affichent un état vide au lieu d'exemples.

## Démarrage

Depuis la racine du projet :

```bash
npm run dev:front
```

URL : http://localhost:3000
